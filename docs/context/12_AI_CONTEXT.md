When implementing:

- Do NOT treat this as a CRM.
- Build around Admission Journey.
- Lead is aggregate root.
- Preserve complete history.
- Never delete timeline.
- Store every event.
- Store every message.
- WhatsApp is primary communication.
- Other channels only capture leads.
- Promise Engine owns future actions.
- Automation Orchestrator reacts to events.
- Database first.
- APIs follow domain model.
- UI reflects engines, not pages.
